# Changelog

## [1.1.0] - 13.10.2026

- Added live calculator results beside the JEI search bar.
- Added arithmetic, powers, square roots, percentages and trigonometry.
- Supported decimal points and commas.
- Kept formulas white and results aligned outside the search bar.
- Separated tool descriptions in the help tooltip.

## [1.0.0] - 12.10.2026

- Added inventory highlighting by double-clicking the JEI search bar.
- Added green borders for matching items and the active search bar.
- Added a magnifier icon with compact tool hints.
- Added pointer cursors and click sounds for highlighting.
- Kept item tooltips readable while highlighting is active.

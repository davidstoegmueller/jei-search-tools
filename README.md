# 🔎 JEI Search Tools

More ways to use your JEI search bar.

**JEI Search Tools** is a client-side addon for **Just Enough Items (JEI)** that adds a growing collection of search-bar tools. Each tool offers a useful interaction through JEI's familiar search interface, with simple controls and clear feedback.

More tools are planned. Hover the magnifier beside the search bar to see the available tools and how to use them.

## 🧰 Included tools

### 🟩 Inventory Highlighter

Find matching items in your inventory and open containers. Matches receive a green border, while other slots are dimmed. Items remain usable and tooltips stay readable.

**Use:** enter a JEI search, then double-click the search bar to toggle highlighting.

Install JEI Search Tools and its dependencies in your client's `mods` folder. No server installation is required.
